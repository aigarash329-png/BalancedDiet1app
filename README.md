# BalancedDiet1app
Balanced diet suggestion
A lightweight, interactive web application designed to help users select nourishing, balanced daily menus based on their current physical and mental well-being. Built with holistic health principles in mind, the app features custom character illustrations to guide users through an engaging meal-selection experience.  
FeaturesInteractive Menu Selection: Guides users through three quick questions assessing their physical condition, preferred ingredients, and cooking style/time.  Personalized Recommendations: Generates tailored meal plans (featuring main dishes, side dishes, and soups) categorized by vitality, relaxation, or recovery needs.  Character Guidance: Integrates avatar expressions (MiniAyuHello.png, MiniAyuThink.png, MiniAyuHappy.png, etc.) to create a warm and supportive user experience.  Zero Dependencies: Built as a single, self-contained HTML file with embedded CSS and JavaScript, requiring no external frameworks or build tools.
